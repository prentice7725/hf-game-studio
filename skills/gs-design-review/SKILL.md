# 설계 리뷰

Claude-Code-Game-Studios의 `design-review` 스킬을 hf-game-studio용으로 줄인 것이다(MIT, NOTICE.md 참고).
읽기 전용이다. 고칠 일은 hyperfusion 작업(gdd, lore)으로 넘긴다.

## 점검 항목

인자로 받은 문서(없으면 `design/gdd.md`)의 각 규칙·섹션에 대해:

1. **구현 가능성:** 발동 조건, 효과, 실패할 때가 모두 적혀 있는가? 프로그래머가 물어봐야 하는 빈칸이 있는가?
2. **수치 연결:** 숫자마다 "수치와 공식" 표의 공식 이름이나 데이터 파일이 연결되어 있는가? 연결 안 된 숫자는 TBD로 표시되어 있는가?
3. **기둥 연결:** 각 메커닉이 어느 기둥(pillar)에 봉사하는지 말할 수 있는가?
4. **단일 원본 일치:** 고유 명사가 `design/glossary.md`에 있는가? `design/world.md`와 모순되는 설정이 있는가?
5. **범위:** "범위 밖"에 적힌 것을 다시 요구하는 규칙이 있는가?
